## What learning without AI actually looked like

- **Errors were puzzles, not prompts.** When something broke, I had to read the error message, guess, change one thing and try again. I spent [VERIFY: "a whole weekend"] once on a missing closing `div`.
- **Stack Overflow was the oracle.** You searched, found a question from 2013 that was almost your problem, and adapted the answer. Adapting is a skill. It forces you to understand.
- **Tutorials ended and you were alone.** Every course ended right before the hard part. Finishing projects past the tutorial is where I actually learned.
- **Shipping was hard.** Getting a site online meant figuring out hosting, domains and FTP. [VERIFY: mention the first host or tool you used.]

## Habits that slow way of learning gave me

1. **Reading code before writing it.** I learned more from reading other people's source than from any course.
2. **Debugging by isolating.** Comment things out, shrink the problem, test one assumption at a time. It's still my most-used skill.
3. **Patience with not knowing.** Being stuck for an hour felt normal, so it never scared me off.
4. **Finishing.** No one finished things for me, so I learned to.

## Then AI arrived

When chat-based AI tools went mainstream after ChatGPT launched on November 30, 2022, my first reaction was honestly a bit of resentment: "I spent nights figuring this out, and now anyone can just ask?" That faded fast. I realised AI was most useful to people who already knew what a good answer looked like.

Today I use AI daily ([here's how AI changed my development workflow](/blog/how-ai-changed-software-development)). But I notice a difference between developers who learned the fundamentals and those who only ever prompted. The first group spots when the AI is wrong. The second group ships the bug.

## How I'd learn to code as a teenager today

If a 13- or 14-year-old asked me how to start in 2026, this is what I'd say:

- **Build something you actually want.** A page for your football team, a tool for your homework, a site for a relative's shop. Motivation beats curriculum.
- **Use AI as a tutor, not a ghostwriter.** Ask "why does this work?" and "what's wrong with my approach?" more than "write this for me."
- **Follow the rule I still use:** don't keep any code you can't explain line by line.
- **Type it yourself first.** For the first few months, write the code by hand and let AI review it. Then flip it.
- **Learn the boring basics properly:** HTML structure, CSS layout, JavaScript fundamentals, how the browser loads a page, Git.
- **Put things online.** A live link teaches you more than a folder of unfinished projects.

## FAQ

### What age should you start learning to code?
There's no magic age. If you can read comfortably and you're curious, you can start. I started at [AGE] [VERIFY]. What matters more is building real things consistently.

### Should beginners use AI to learn programming?
Yes, carefully. Use it to explain concepts and review your code. Avoid letting it write everything, or you'll skip the part where you actually learn.

### What should a teenager learn first: Python or web development?
Either works. I'd pick web (HTML, CSS, JavaScript) if you like seeing results instantly in a browser, and Python if you prefer logic puzzles and automation.
