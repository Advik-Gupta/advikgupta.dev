# advikgupta.dev

Personal site of Advik Gupta.

Built with Next.js, GSAP, Lenis, Framer Motion and Matter.js.

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Environment

| Variable | Description |
| --- | --- |
| `NEXT_PUBLIC_RESUME_URL` | Link opened by every "See resume" button. Buttons are hidden when unset. |
